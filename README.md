# Python Day 130 - Second Largest Number

This Python program finds the second largest distinct number in a list.

## Example

Input list:
```text
[10, 40, 20, 50, 30]
```

Output:
```text
Largest number: 50
Second largest number: 40
```

## Concepts Used

- Lists
- `max()` function
- `for` loop
- `if` statement
- Comparison operators
- Variables

## How It Works

The program first finds the largest number using `max()`. It then checks every number in the list and finds the greatest number that is smaller than the largest number.
